**Long rests (#89 + #346, owner ruling 2026-09-05 — evening-anchored):** a rest that BEGINS in the evening window (18:00 through 03:59 clock time) rolls to the next dawn; one that begins in daylight (04:00 through 17:59) sleeps a fixed eight hours (6:37 am → 2:37 pm). `clockSleepMode()` decides from the start instant, `clockSleepRoll()` applies; the ONE roll site is `restSpells()`, so the Rest button and the `[REST:long]` tag can never double-roll, and the same response's `[TIME_ADVANCE:]` is absorbed in both modes. Pinned by the #89/#346 tests and `dev/sabotage-346-sleep-roll.js`.

- **The named wake (#389, v1.876, owner ruling 2026-09-09).** A long rest rolls to the phase the GM NAMED: `clockNamedWake(text)` maps the LAST same-response `[TIME:]` (never `[TIME_CHECK:]`) through `TIME_PHASES` and returns it only when it is OUT of band at the pre-rest clock; the REST handler parks it on the transient `worldState.restWake` (deleted after the roll, never persisted), `clockSleepMode` answers `"named"`, `clockSleepRoll` advances to that phase's next occurrence, the mut reads `slept until <phase> (named)`, and the tail reconcile then no-ops in band. An in-band `[TIME:]` is a declaration of the phase the scene is already in and keeps the #346 fixed eight hours (the t37 guard); the #142 demanded heal (`reconcileSkip` armed) keeps precedence. Field origin: The Long Walk t122–t125, the double night. Note order half: `buildWhispersNote` yields while `reconcileSkip` is armed.
- **The GM reads the phase, never derives it (#387, 2026-09-08).** `buildClockBlock` speaks the phase word (`clockPhaseLabelAt`, narrowest band; the clock face itself stays display-only) and names the `[TIME_CHECK:]` to open with; a structured declaration outside its own band by more than `PHASE_CHECK_GRACE_MIN` (60m) arms the reconcile nudge with `src:"check"` and the clock's phase in the text, while the fuzzy prose recogniser keeps `PHASE_MISMATCH_MIN` (240m). Field origin: The Long Walk t95–99, `[TIME_CHECK:dawn]` five turns running against an 8:00–9:45 am clock, each copied from the previous response — the block only gave the GM elapsed minutes to convert.
- **The reconcile cap, both directions (#142 + #368, owner ruling 2026-09-07).** A bare `[TIME:phase]` tops the clock up to the phase only when the roll is at most `RECONCILE_SKIP_MIN` (6h); a larger roll — across dawn OR on the same day (the t2366 phantom night: dawn → late night on continuous fiction, +1,140m) — is presumed a mislabel: the text is kept, nothing rolls, `worldState.reconcileSkip` (with `sameDay`) arms `buildReconcileSkipNudge`, which names the direction and the sanctioned doors (`[REST:long]`, `[TIME_ADVANCE:]`). The #270 post-band grace is unchanged. **The out-of-character hold (#368):** a story-box action opening `GM:`/`OOC:` (`oocActionPrefix`) is answered in the fiction but never charged — `sendAction` arms `worldState.clockHold` for that one turn (toast), `clockAdvance` returns 0 while it stands, and the next action clears it. Pinned by the #368 section and `dev/sabotage-368-reconcile-hold.js`.
- **Repairs and rescue (#146, #274).** `clockRepair(id, expectedMin, delta)` is the ONE sanctioned correction: it refuses a repeat id (the receipt rides the save, so a second run on any device refuses), a state mismatch (the anomaly it targets is not present), and — queue entry 33's remedy — a delta that is not a finite whole number of minutes. A corrupt scalar (`min` not a finite number) is never wiped: `clockRescueCorrupt` preserves the unreadable clock verbatim under `CLOCK_RESCUE_K + campId` (one slot, newest wins), shouts on both channels naming the value and its type, then rebuilds CARRYING `schedule[]` and `repairs[]` when they are still arrays. ABSENT is distinct from CORRUPT: a save with no clock mints one silently (a legacy load). Batteries: `sabotage-274-clock-rescue.js`.
